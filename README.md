# El viaje de Laura

Página con el itinerario de Laura por Europa (25/11/2026 al 06/01/2027): paisajes vectoriales en parallax, cuenta regresiva, hora local, clima en vivo y horas de sol de cada parada.

Todo está en `index.html`. Para cambiar fechas o lugares, editá el array `ITINERARIO` al principio del script. La hora de salida está en la constante `SALIDA`.

Para ver cómo se vería un día del viaje: agregá `#simular-2026-12-04` al final de la URL.

Clima: [Open-Meteo](https://open-meteo.com/) (CC BY 4.0).
